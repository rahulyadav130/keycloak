# keycloak
Keycloak se kya milta hai?
Single Sign-On (SSO): Ek baar login karne par multiple apps mein bina dobara login kiye access.
OAuth 2.0 aur OpenID Connect (OIDC): Modern standard protocols, jo aaj ke web aur mobile apps mein use hote hain.
SAML 2.0: Purane enterprise apps ke liye.
User Federation: LDAP ya Active Directory se users ko connect karna.
Social Login: Google, GitHub, Facebook jaise providers se login.
MFA (Multi-Factor Authentication): OTP ya extra verification.
Admin Console: Web UI se sab kuch configure karna.
